# BlackwallPass

Менеджер паролей на Android с Zero-Knowledge архитектурой. Данные шифруются на клиенте (AES-256), бэкенд используется только для синхронизации зашифрованных слепков.

## Стек
*   **UI:** Jetpack Compose (UDF, чистый Compose без XML-legacy, оптимизация рекомпозиций)
*   **Архитектура:** MVVM (Single Activity + Navigation Component)
*   **Асинхронность:** Coroutines, StateFlow / SharedFlow для передачи состояний экранов
*   **Бэкенд / Auth:** Supabase
*   **Криптография:** AES-256 + генерация KEK (Key Encryption Key) на стороне клиента
*   **Сборка:** Gradle (Kotlin DSL)
